# CALIBRE KAKKANAD

Proposed integrated rehabilitation and recovery clinic in Kakkanad, Kochi.

## Repository status
This repository was initialized on 7 October 2026. It is currently public. Confidential budgets, landlord negotiations and historical project plans are intentionally excluded.

## Project scope
One integrated clinic with six physiotherapy treatment cubicles: three male and three female. Planned services include active rehabilitation, recovery, doctor consultation and nutrition. Opening date and bookable services are not yet confirmed.

## Complete project package
A reviewed internal Next.js planning package has been prepared separately. Change this repository to Private before uploading it. Do not upload patient data, credentials or agent transcripts. Retain existing Git history; do not force-push.
