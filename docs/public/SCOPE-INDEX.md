# Scope index

Planning status: 7 October 2026.

This index gives one public row for each scope ID from SC-001 to SC-062. Status values mean:

| Status | Meaning |
|---|---|
| `open` | The offering stays in the concept. Specification, staffing, or workflow is still required. |
| `unselected` | More than one approach is still on the table. No system, device, or menu is chosen. |
| `deferred` | Kept for a later explicit decision. Not part of the current opening plan. |
| `fixed` | Reserved for a locked specification. **No service row is `fixed` yet.** The six-cubicle split is a facility decision, recorded in the [facility register](FACILITY-REGISTER.md). |

Source treatment names are planning entries. They are not approved protocols, prescriptions, product endorsements, or outcome claims.

The 62 IDs were not listed one-by-one in the uploaded originals. This file is the public register. Where an older README range named the same ID twice, the split below is the one to use.
